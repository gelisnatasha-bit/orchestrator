# Книга чек-листа

Файл: `Чек-лист_Автооплата.xlsx`. Четыре листа. Отдельный сервер не нужен, файл открывается в Excel или LibreOffice Calc.

## Сводка

Считает отметки Result с листа «Чек-лист»: всего, пройдено, не пройдено, блок, не применимо, без отметки. Разбивка по разделам. Формулы не затирать при добавлении строк: диапазоны должны включать новые строки данных.

## Чек-лист

155 проверок, строка 1 — заголовок. Колонки слева направо:

1. №
2. ID требования (`APD_GR…`, `APD_SMS…`, `APD_CASH…`, «Термины», «Services interaction» и другие разделы документа)
3. Раздел
4. Проверка
5. Precondition
6. Event
7. Expected result
8. Result — пустая, список: «Пройдено», «Не пройдено», «Блок», «Не применимо»
9. Связка — код `С-01` … `С-19`. Несколько кодов пишутся через запятую. Серый фон значит, что строка входит в несколько прогонов. Пустая связка — отдельный прогон.
10. Роль в связке — `главный` или `попутно`, с указанием кода, если связок несколько. Пример: `С-01: попутно; С-19: попутно`.

Фильтр автофильтра включён. Чтобы увидеть один прогон: фильтр по столбцу «Связка» → текстовые фильтры → содержит → код, например `С-01`.

## Связки

Расшифровка 19 прогонов. Колонки: Код, Связка, Главный №, Главная проверка, Попутные №, Что посмотреть в том же прогоне.

Сначала выполняется строка с ролью «главный», затем в том же состоянии строки «попутно». Result ставится в каждой. Попутный номер закрывается только при условии, которое написано в колонке «Что посмотреть».

## Кейсы

Второй чек-лист по тем же 19 прогонам. Колонки:

1. Кейс — объединена на все шаги прогона, внутри код и название
2. Шаг
3. Действие
4. Куда смотреть
5. Что проверить
6. Ожидаемый результат
7. Result — пустая, тот же список значений. Если условие шага не наступило, человек ставит «Не применимо»
8. № проверки — номер строки листа «Чек-лист», которую закрывает шаг

Слева один кейс, внутри несколько шагов, Result у каждого шага. Новый шаг не теряет номер детальной проверки.
