# Orchestrator

Это главный репозиторий аккаунта [gelisnatasha-bit](https://github.com/gelisnatasha-bit).

Он нужен для двух вещей:

1. **Хранить общие правила** — как ассистенту объяснять и как вести проекты.
2. **Создавать новые репозитории** этого аккаунта уже с этими правилами внутри.

Новые проекты кладём в `G:\Projects\personal`, не на диск C (там мало места).

## Как устроено

| Папка | Зачем |
|-------|--------|
| `rules/` | Человекочитаемый список правил. Это источник правды. |
| `.cursor/rules/` | Те же правила в формате Cursor, чтобы они работали в этом репо. |
| `templates/new-repo/` | Заготовка: копируется в каждый новый репозиторий. |
| `.cursor/skills/` | Пошаговая инструкция для ассистента: как завести новое репо. |

## Правила сейчас

1. [Технический уровень](rules/technical-level.md) — подробные объяснения простыми словами.
2. [Gitflow без PR](rules/gitflow.md) — фича = своя ветка и worktree; **Готово** вливает в `master`.

## Новый репозиторий

Попросите ассистента: «создай репо …». Он должен скопировать `templates/new-repo/` в новую папку, сделать git и привязать GitHub под этим аккаунтом.

## Как закончить фичу

Напишите **Готово** или вызовите `/Готово`. Ассистент вольёт ветку в `master` (без pull request), отправит её на GitHub и уберёт worktree.
