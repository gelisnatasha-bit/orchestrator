# Готово

Влей текущую фичу в основную ветку. Без pull request.

Это алиас финиша для аккаунта gelisnatasha-bit. Правило gitflow лежит в `.cursor/rules/gitflow.mdc`.

## Что сделать

1. Определи репозиторий, ветку фичи и папку worktree. Основная ветка — `master`; если её нет, а есть `main` — используй `main`.
2. Если есть незакоммиченные изменения — закоммить их (понятное сообщение, без секретов). Не пропускай хуки.
3. Убедись, что `git status` чистый.
4. В **основной** папке репозитория (не в worktree фичи):
   - `git checkout` основной ветки
   - `git pull`
   - `git merge --no-ff` ветки фичи
   - `git push origin` основной ветки
5. `git worktree remove` папки фичи, затем `git branch -d` ветки фичи.
6. Переведи агента обратно в основную папку (`move_agent_to_root`) и на основную ветку (`SetActiveBranch`).

Не создавай PR. Не вызывай `gh pr create`. Не делай force-push. Если конфликт — остановись и объясни простыми словами.
