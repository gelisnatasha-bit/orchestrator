# Этот проект

Репозиторий аккаунта [gelisnatasha-bit](https://github.com/gelisnatasha-bit). Общие правила приходят из [orchestrator](https://github.com/gelisnatasha-bit/orchestrator).

Следуй `.cursor/rules/` в этом проекте.

- Технический уровень: объясняй подробно и простыми словами.
- Gitflow без PR: фича = своя ветка и worktree. Команда **Готово** или `/Готово` вливает изменения в `master`. Pull request не создавать.
- Код комментируй и документируй: зачем нужен кусок, что делают функции, README у модулей.
